# ADEN STUDIO
Basic GitHub Pages-ready men's fashion website.

## Upload
Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of your GitHub repository.

## Enable GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your site will then be available at:
https://adenstudio1908.github.io/ADEN-STUDIO/

Replace `assets/aden-logo-reference.png` with your own campaign/product photos and edit the product array in `script.js`.
